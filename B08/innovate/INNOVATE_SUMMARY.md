# B08 创新模块汇总（INNOVATE_SUMMARY）

> 三个创新模块为**独立后置分析工具**：证据可信度打分、风险溯源链路可视化、历史风险轨迹差分对比。
> 基于已冻结 B08 baseline（app_version=B08_baseline_01、model_version=b06-rf-v1、kb=b04_kb_v1），
> 未改动 B01~B07、B08 原有推理代码与边界检查脚本；只读原始文件、不覆盖旧数据。

## 模块清单与用法

| 模块 | 脚本 | 功能 | 用法 |
| --- | --- | --- | --- |
| 1 证据可信度打分 | score/evidence_score.py | 四类证据 0~1 单项分 + 加权综合（时序 0.5/天气 0.3/知识 0.2，模型单项单独展示）+ 置信文案 | --file / --dir |
| 2 风险溯源可视化 | trace_view/render_trace.py | Markdown 树形 + 静态 HTML（VIEW 样式统一）；归因方向复用 S4 分类，不编造 | --file / --dir --outdir |
| 3 历史轨迹差分 | diff_snap/snap_diff.py | 同场景跨 run 对比 verdict/趋势斜率/可信度/证据状态，只输出客观差异 | --file-a --file-b / --dir |
| 串行入口 | run_innovate.py | 单次 run 流程末尾串行执行：打分 → 溯源视图 → 差分；B08 新 run 追加 _innovate 字段（原有字段保留），B01~B07 只读 | --file / --b08 / --b07-dir |

## 打分规则（透明）

- **时序（0.5）**：离群跳变（相邻温差>5℃或湿度差>20%）每处 -0.1；数值越界（温度 0~50/湿度 0~100/光照 0~120000）每处 -0.2；有效历史点不足 7 个每缺一点 -0.1
- **天气（0.3）**：调用失败/超时/字段缺失 → 单项 0；正常且字段齐全 → 1.0
- **知识库（0.2）**：citation 缺失 → 0.2；citation 在但无片段详情 → 0.4；匹配度按检索得分归一化
- **模型（单项展示）**：无输出 → null；概率区分度 ≥0.7 → 1.0
- **快照完整性**：run_id/created_at 缺失 → 每项 -0.1（最多 -0.3）；文件损坏 → 综合 0
- **语义区分**：场景无某类证据 → 单项 null（综合权重归一化剔除）；证据存在但失效 → 单项 0（参与加权）——「没有」≠「坏了」
- 置信文案：≥0.8 证据充足参考价值高；0.4~0.8 证据存在瑕疵仅供参考；<0.4 证据质量差建议复核数据源
