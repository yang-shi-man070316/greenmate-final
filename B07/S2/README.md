# GreenMate B07/S2 · 渐进漂移对照实验

**同一瞬时温度、同一提问、同一模型、同一配置，仅 B02 历史时序数据不同**——验证系统能否
自主从时序历史中识别「持续升温漂移」并给出与稳态基线差异化的风险结论。

- 硬性约束：不新增模型/接口/知识库，完全复用 S1 链路（B02 时序、B06 模型、B01 LLM），禁止重写、禁止改模块逻辑
- 唯一变量：**B02 历史时序数据**（S2 漂移段由本目录脚本注入，天气源/知识库/提示词/模型参数全部固定）
- 无人工提示：不添加「温度在上升」等任何提示词，趋势识别完全依赖系统读取时序历史

## 快速开始（项目根目录）

```bash
python B07/S2/tests/test_s2.py        # 测试（无需 LLM Key）
python B07/S2/run_experiment.py       # 执行 S2 漂移场景完整链路（需 .env 密钥），输出 run_id
python B07/S2/report.py               # 生成正式对照实验报告 → docs/EXPERIMENT_REPORT.md
```

## 实验设计

| 场景 | 当前瞬时 | 近 3 小时历史 |
| --- | --- | --- |
| S1 基线（复用 S1 原始记录） | ≈30.4℃（10-20 16:30） | 稳定 28.9~30.4℃ 小幅波动，无持续升降 |
| S2 漂移（drift_inject.py 注入） | ≈30.0℃（10-20 20:00） | 25.0→30.0℃ 匀速渐进升温（每 30 分钟 +0.83℃），持续上升 |

统一固定提问（两组完全一致）：「分析当前番茄生长环境状态以及接下来值得关注的变化，并说明判断依据。」

漂移段注入方式：向 B02 库尾**追加** 7 点（不覆盖 S1 稳定段，两组数据都真实存在于 B02）；
温度 25→30℃ 线性、湿度 50→47.3% 微降、光照 12000→10 lux 傍晚回落、sim_scenario=normal。

## 实测结果（2026-10-21）

| 维度 | S1 基线 | S2 漂移 |
| --- | --- | --- |
| 当前瞬时温度 | 30.4℃ | 30.0℃（几乎一致） |
| 温度幅差 | 1.5℃ | **5.0℃** |
| 前后半均值差（趋势） | +0.40℃/窗口 | **+2.92℃/窗口（持续上升）** |
| 模型预测（b06-rf-v1） | NORMAL（1.0） | NORMAL（0.9243） |
| **风险判定** | **stable** | **attention** |
| **关注等级** | **低（无需重点关注）** | **高（需要重点关注）** |

**验收结论**：两组输出差异化结论 ✅ —— S1 判定环境稳定无风险；S2 识别升温漂移、判定潜在变化风险、
需要重点关注。差异完全来自时序历史数据，无人工提示词干预。

值得注意：S2 中 B06 模型仍预测 NORMAL（0.92），但结构化判断基于历史趋势（幅差 5℃、half_diff +2.92℃）
独立判定为 attention——**趋势检测抓到了模型漏掉的风险**，且未修改模型输出（model_output_modified=false），
LLM 解释中也如实说明了「模型预测与结构化判断不一致，以结构化判断为准」。
